Bybit V1 Backup

Bybit V1 Backup is a private, personal-use utility for storing encrypted backup files from an automated market-data research project in the owner's Google Drive.

The utility uses Google OAuth authorization and the Google Drive API with the drive.file scope. This enables it to create and manage files associated with the application rather than accessing the owner's entire Google Drive.

Backup files are intended to be encrypted on the owner's server before upload. The application is not a publicly offered product and does not execute financial trades.

For details about data use and retention, read the Privacy Policy.
